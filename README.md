# rallylabs.ai

One-page site for Rally Labs. Plain HTML, no build step, hosted on GitHub Pages.

## Files

- `index.html` — the whole page (logo, copy, constellation animation)
- `CNAME` — tells GitHub Pages to serve this at rallylabs.ai
- `favicon.svg`, `apple-touch-icon.png` — browser tab and home-screen icons
- `og-image.png` — the preview card when the link is shared in iMessage, Slack, LinkedIn

## Quick edits (all in index.html)

- Tagline: search for `We make the algorithm physical.`
- Rotating lines: the `phrases` list near the top of the script (also update the hidden `sr-only` sentence under it so screen readers match)
- Contact: search for `mailto:` (currently sean@rallylabs.ai)

Commit the change on github.com and the site updates in a minute or two.
